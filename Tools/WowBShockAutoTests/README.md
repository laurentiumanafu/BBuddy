# Shock and Attack checks

`python Tools/WowBShockAutoTests/test_shock_structure.py` checks source wiring only. With a .NET 10 SDK, `python Tools/WowBShockAutoTests/run.py` checks wiring and executes the extracted input guard with synthetic state. `Tools/WowBReaderTests/RotationTests.cs` tests the production rotation policies, including the logged 70862 Frost Shock/Attack bar and overrides. These do not execute a full fight or show the live client's swing state. Attack is an unverified toggle: it is attempted once per hybrid Fight and never retried merely because damage is quiet. The optional 70862 post-heal Start Attack binding is separate and user-configured; its behavior and swing state are unverified (see `Tools/WowBPostHealAttackTests`).
