# Full-bag town return: current status

The requested recall → sell → mailbox → mail → resume sequence is **not complete**. On 70938 Grind, after the existing vendor plan is replayed, a mailbox position recorded for that plan now starts a mesh-only route to the recorded standing point. Combat or an unreadable safety state interrupts the route; it remains pending and the normal Grind defence can run before the route resumes. The vendor replay is not repeated because of a mailbox-route interruption. A failed mesh route or arrival at the recorded point stops Grind for manual attention. The bot does not detect a mailbox object, open it or send mail. No sale or inventory contents are verified.

To set up, stop the bot, select a plan with a recorded town on the same map, stand beside the mailbox and use Selling → Record mailbox here. Recording the town again clears the saved mailbox and merchant confirmations. With no mailbox recorded, existing selling behavior remains unchanged. Gather does not currently run this workflow.

**Astral Recall and Hearthstone are not implemented.** A new research-only 70938 observer recognizes the recorded Astral Recall and Hearthstone candidates, but it is not wired to gameplay or validated against a completed teleport. The requested logic requires observing a cast, distinguishing a genuine interruption from an unknown or unobserved cast, waiting for cast end and a stable location change, defending during combat, and handling cross-map destination and mesh/session changes. A keypress is not a cast, and an unchanged location by itself does not prove an interruption. Never automatically repeat an unobserved cast or resume movement while it might still be in progress. No Lua is authorized after the earlier crashes.

Existing 70938 Grind automatic selling depends on experimental ordinary-bag classification and a stable zero free-slot candidate, and only uses complete vendor plans on the current map. The recorded click replay does not verify the merchant window, the sale or which items were sold. Existing mail code is legacy and must not be assumed usable with 70938. A location alone does not identify a recipient, item contents, mail attachment slots or the send button. Do not infer success from a posted key/click, and do not blindly resend mail or sell/mail arbitrary bag slots.

Local fixture coverage is synthetic; Windows build and in-game verification remain necessary.
